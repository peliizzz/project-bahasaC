## SKULROOM

Aplikasi berbasis bahasa C yang berjalan di terminal (console) Windows, berfungsi
sebagai buku digital sederhana untuk menyimpan dan mengelola materi pembelajaran.

## Fitur

- Login admin
- Tambah, tampilkan, ubah, dan hapus materi
- Tampilan menu interaktif dengan navigasi tombol panah

## Struktur File

| File          | Kegunaan                          |
| ------------- | ---------------------------------- |
| `main.c`      | File utama program                 |
| `tampilan.c`  | Tampilan menu dan pengolahan file  |
| `validasi.c`  | Validasi input pengguna            |
| `materi.txt`  | Penyimpanan data materi            |
| `admin.txt`   | Penyimpanan data admin             |
